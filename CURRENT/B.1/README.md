# Mechanical design revision B.1

## Changelog

- Repositioned the Back plate's snap-fit notches used for attaching external module covers
- Added cable-management channels to the Antenna rail for routing SMA cables
- Increased the Loop size so that cables with Ethernet, HDMI, and USB-A connectors can be pushed through it
- Added an additional screw to secure the Back plate
- Replaced the screws on the Back plate and Antenna rail with PH screws (DIN 965H M2.5 × 6 mm)
- Increased the App switcher button height by 0.25 mm
- Redesigned the LAN port openings so that the connector LEDs are now visible
- Increased the microSD card opening size and adjusted the slot depth. The microSD card should no longer protrude from the enclosure
- Increased the nanoSIM opening size and adjusted the slot depth. The card should now be easier to insert
- Raised the wattmeter display surface for better visibility and updated the wattmeter graphics according to the mechanical design
- Redesigned the area above the Wi-Fi module and added a new cable-management part for routing the Wi-Fi and BLE antenna cables. This part also covers the GPIO connector
- Moved the 3.5 mm jack closer to the outer edge of the enclosure so that all plugs can now be fully inserted
- Changed the Link LED light guide to a circular shape
- Added physical concentric circles to the touchpad surface
